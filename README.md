# Count Your Work

A simple batch-counting app built to help my mom track her completed work. I built it as a hands-on project to practise JavaScript and solve a real-life problem.

### Features
- Batch counting and confirmation
- Date and time-based history
- Monthly history grouping
- Local storage for saved records
- Responsive design
- Offline support using a service worker
- PWA manifest and app icons

### Built With
HTML · CSS · JavaScript

### What I Learned
DOM manipulation, event listeners, arrays, objects, localStorage, date handling, service workers, caching, and PWA basics.

### Run Locally
Open the project in VS Code and launch it using Live Server.
